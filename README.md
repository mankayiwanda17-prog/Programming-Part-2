# QuickChat Application

## 1. Introduction

QuickChat is a messaging application that I developed using Java in Apache NetBeans as part of my PROG5121 assignment at IIE Rosebank College.

The main aim of this project was to create a simple application where users can register, log in and send messages. It also helped me understand how different parts of a Java program work together.

## 2. What the Application Does

QuickChat allows users to perform different tasks, such as:

- Registering an account with a username and password.
- Logging in using their registered details.
- Checking whether the information entered by the user is correct.
- Creating and sending messages.
- Generating unique IDs for messages.
- Viewing and managing messages.

The application is designed to be simple so that users can understand how to use it.

## 3. Software Used

I used the following software to develop this project:

- **Java:** To write the code and create the application.
- **Apache NetBeans:** To write, organise and run my Java code.
- **JUnit:** To test different parts of the application and check whether they work correctly.

## 4. How to Run QuickChat

To open and run the application:

1. Open Apache NetBeans on your computer.
2. Click on File and select Open Project.
3. Find the QuickChat project folder and open it.
4. Locate the main Java class.
5. Right-click the class and select Run File.
6. Follow the instructions that appear on the screen.

## 5. Testing the Application

Testing is an important part of this project because it helps me identify mistakes in my code.

I used JUnit to check different functions, including username validation, password validation, login details and message handling.

The purpose of these tests is to make sure the application works as expected and responds correctly when users enter different information.

## 6. What I Learned

While working on QuickChat, I gained a better understanding of Java programming.

I learned how to create classes and methods, use conditional statements, work with loops and validate user input.

I also learned how to organise my code into different sections instead of putting everything into one class.

Another important skill I gained was testing my code using JUnit. This helped me understand why testing is necessary when developing an application.

## 7. Challenges I Experienced

One of the challenges I experienced was making sure that the different Java classes worked together correctly.

I also had to deal with coding errors and understand what was causing them.

Working through these challenges helped me improve my problem-solving skills and become more comfortable using NetBeans.

## 8. Conclusion

Overall, developing QuickChat was a useful learning experience. It allowed me to apply what I learned in PROG5121 to a practical Java project.

Although some parts of the application were challenging, the project helped me improve my coding, testing and debugging skills.

I now have a better understanding of how a Java application is developed and how different classes work together to perform specific tasks.
